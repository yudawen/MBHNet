# MBHNet

Datasets of the paper:

> **Spatial-Channel Selective State Space Models and Pruned Cross-Task Feature Transfer for Building Height Mapping from Aerial Images and DSMs**

## Datasets

### Tianjin Dataset

The **Tianjin Dataset** contains approximately **572 MB** of data.

The dataset is publicly available through Baidu Netdisk:

- **Download link:** https://pan.baidu.com/s/1V8rdQcdXRx183oiwRfUCoQ
- **Extraction code:** `tjda`

### GeoNRW Dataset

The **GeoNRW Dataset** contains approximately **9.2 GB** of data.

The dataset is publicly available through Baidu Netdisk:

- **Download link:** https://pan.baidu.com/s/10swG2ejDe7_I79cRtqcpLQ
- **Extraction code:** `gnrw`
